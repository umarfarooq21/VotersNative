# Liquid Glass MVVM App

A modern iOS application built with **SwiftUI** that follows Apple's latest **Liquid Glass Design** language and uses the **MVVM (Model-View-ViewModel)** architecture pattern for clean, scalable, and maintainable code.

## Features

- ✨ Apple-inspired Liquid Glass UI Design
- 📱 Built entirely with SwiftUI
- 🏗️ MVVM Architecture
- 🔄 Reactive UI updates
- 🎨 Modern and clean user interface
- 🌙 Supports Light and Dark Mode
- 📂 Well-structured project organization
- 🚀 Scalable and maintainable codebase

## Architecture

This project follows the **MVVM (Model-View-ViewModel)** pattern:

### Model
Responsible for managing data structures and business models.

### View
SwiftUI screens and reusable UI components responsible for presenting data.

### ViewModel
Acts as the bridge between Views and Models, handling business logic, state management, and data transformations.

```
View
  ↓
ViewModel
  ↓
Model
```
